# Damp

**Drink less. Not never. One tap a night.**

An iOS drink-less tracker built to the same recipe as Clam ("30,600 apps" research): proven
market, one-sentence pitch, onboarding that sells, hard paywall, one core loop, shareable
result. Aimed at the sober-curious / "damp lifestyle" market, launching for Sober October
(1 Oct 2026) and built to peak in Dry January.

## What's in the box

| Target | What it is |
|---|---|
| `Damp` | SwiftUI app: 9-step onboarding, first-night "taste", StoreKit 2 paywall, home (streak, week strip, one button), drinks log sheet, milestone cards + share, settings, nightly check-in notification with tap-to-log actions, Siri/Action Button intent |
| `DampWidgets` | Home Screen widget: streak, money kept, one-tap "Tonight's dry" |
| `DampTests` | Unit tests for streak, savings math and the reveal numbers |
| `Shared` | App Group constants shared by app and widget |

No backend. Local notifications, StoreKit 2, WidgetKit, App Intents, UserDefaults in an App
Group. No restricted entitlements, so there is nothing to wait for from Apple except review.
Analytics events go to the console and, once a key is set in `Damp/App/Config.swift`, to
PostHog (anonymous, no session replay).

## Build

The Xcode project is generated from `project.yml`, so there is no `.xcodeproj` checked in.

```bash
brew install xcodegen
xcodegen generate
open Damp.xcodeproj
```

1. Set your team on the app and widget targets (Signing & Capabilities).
2. Bundle IDs are `app.usedamp.damp` and `app.usedamp.damp.widgets`, matching the usedamp.app domain.
3. **Simulator** runs the whole thing: onboarding, paywall (StoreKit test config), logging,
   milestones, widget. Notification actions work but fire more reliably on a device.
4. The `Damp` scheme uses `Damp/Resources/Products.storekit`, so the paywall works locally
   without App Store Connect.

Screens: `bash scripts/capture-screenshots.sh "<simulator>"` after installing the app, or run the
`Screenshots` GitHub workflow. Each screen opens with `-screenshot <name>` and seeded data.

## Core loop

```
9pm notification "Dry tonight?" ──Dry ✓──▶ streak +1, money +$11 ──milestone──▶ card ──▶ share
                                 └─Drank──▶ "How many?" ──▶ logged, streak 0, savings kept
```

## Where the numbers come from

- Hook: "$2,900 a year" = one $8 drink × 365 nights. `HookScreen` in `OnboardingScreens.swift`.
- 150 kcal per standard drink and 2,000 kcal per "day of food": `OnboardingAnswers`.
  Cite NIAAA for the drink before submission.
- "Money kept" = (stated drinks per week ÷ 7 × nights logged − drinks logged) × price per
  drink. Conservative on purpose: most people drink on fewer than seven nights.
- Competitor prices (Sunnyside $99/yr, Reframe $99.99/yr) checked 17 Sep 2026.
